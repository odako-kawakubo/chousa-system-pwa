# Odako Chousa System PWA

アスベスト調査システムPWAの本開発版リポジトリです。

現在は、v0.15系の画面構成を整理したUIシェルに、Microsoft AuthenticationとGraphアクセストークン取得確認のみを接続しています。

## 現在のバージョン

`ui-shell-0.2.0`

## 公開

`main`ブランチへのpushで、GitHub ActionsからFirebase Hostingへ自動デプロイします。
