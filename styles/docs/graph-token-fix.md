# Graphトークン表示修正

更新日：2026-08-06

## 修正内容

Microsoftログイン成功後、Graphアクセストークンが `sessionStorage` に保存される前に認証状態監視の画面更新が走り、画面上で「Graphトークン：未取得」と表示される場合がありました。

今回の修正では次を行っています。

- Graphアクセストークンを取得できなかった場合はログイン成功扱いにしない
- トークン保存後に認証UIを再描画
- ログアウト後も認証UIを即時更新
- バージョンを `auth-shell-0.1.1` へ更新

## 確認手順

1. ZIPの内容をリポジトリ直下へ上書きする
2. コミットして `main` へpushする、または手動でFirebase Hostingへデプロイする
3. 一度ログアウトする
4. Microsoftログインをやり直す
5. 上部表示が `Graphトークン：取得済み` になることを確認する

Graphアクセストークンは `sessionStorage` にのみ保存し、GitHubやソースコードには保存しません。
