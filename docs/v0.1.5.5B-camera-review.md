# v0.1.5.5B カメラレビュー版

## 位置づけ
v0.1.5.5A のカメラ実装へパッチを積まず、カメラ関連モジュールを整理して再構成したレビュー版。

## 主な変更
- `camera-controller.js` を全面再構成
  - v64 基準の getUserMedia 条件へ一本化
  - カメラエラー種別と認識カメラ台数の表示
  - iOS / iPadOS 復帰時は live track を再利用し、失効時のみ再取得
  - A のモード/状態バッジ、旧イベント、旧フォールバック処理を削除
  - 目視/採取の対象切替、撮影、レビュー、ローカル保存を一本化
- `camera-board.js` を全面再構成
  - v64 の 390x242 を中サイズ基準として統一
  - プレビューと完成画像で同じ看板描画を使用
- `camera.css` を全面再構成
  - v64 基準の 左92px / 中央4:3 / 右92px
  - 上書きパッチではなく未使用セレクタを削除した完成形へ置換

## Bでまだ行わないもの
- 撮影後の看板編集
- OneDrive 実アップロード / verified
- PC写真取込本体

OneDrive状態は `pending` のまま保持する。
